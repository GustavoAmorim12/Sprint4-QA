A aplicação Find Mottu é uma API REST desenvolvida em Java com Spring Boot, que tem como objetivo gerenciar motos, filiais e usuários de forma centralizada, permitindo operações completas de CRUD (Create, Read, Update, Delete).


O sistema faz parte de um ecossistema voltado ao gerenciamento de pátios de motos e controle operacional da empresa Mottu, permitindo a integração com aplicações web e mobile para consulta e administração de dados.
